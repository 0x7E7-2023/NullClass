# M5 实现文档（概要）：教务系统导入

日期：2026-09-06 · 状态：**概要级**——实现前需重开一份详细文档评审 · 前置：[PROJECT-CONTEXT.md](PROJECT-CONTEXT.md)

> 这是路线图最后一站。各校教务系统差异极大，本里程碑天然是「框架 + 逐校适配器」的长期工程，首版只求框架落地 + 1~2 所学校跑通。**实现前必须先写详细版实现文档走 /stage 流程。**

## 目标

用户在应用内登录自己学校的教务系统，自动抓取课表并导入——WakeUp 课表当年的核心壁垒，也是最大的用户获取入口。

## 架构设想

```
:importer
  └─ jw/                          （教务 = jiaowu）
      ├─ JwImportActivity.kt      （宿主 WebView + 进度 UI + 学校选择）
      ├─ JwAdapterRegistry.kt    （学校 key → Adapter 注册表）
      ├─ JwAdapter.kt            （接口，见下）
      ├─ adapters/
      │   ├─ ExampleUniv.kt       （每校一个文件：选择器 + 解析器）
      │   └─ ...
      └─ JwHtmlParser.kt          （Jsoup 工具 + 公共表格解析辅助）
```

**JwAdapter 接口**（草案）：

```kotlin
interface JwAdapter {
    val schoolName: String
    val schoolKey: String
    /** 登录页与课表页 URL 模板 */
    val loginUrl: String
    /** 注入的 JS：在课表页 DOM 里提取数据为 JSON 字符串 */
    val extractScript: String
    /** 解析提取结果 → ScheduleDocument（复用 M4 的 DTO！） */
    fun parseExtracted(json: String, termInfo: ...): ScheduleDocument
}
```

**流程**：WebView 打开登录页 → **用户手动完成登录**（验证码/扫码/短信都是用户自己操作，应用不碰凭证、不存密码）→ 登录成功后导航到课表页 → 注入 `extractScript`（`evaluateJavascript`）→ 拿到 JSON → 纯函数解析成 `ScheduleDocument` → **直接复用 M4 的 ImportPreview 管线**（预览 + 合并）。

## 关键设计决策（预先锁定）

1. **凭证安全红线**：不解析、不存储任何账号密码；登录全程用户在 WebView 里手工完成。README 与隐私声明明示
2. **纯前端提取**（JS 注入）而非 HTTP 模拟登录——绕过验证码ocr、cookie 管理的复杂性，且各校登录流程差异被完全屏蔽；代价是用户多两次点击，可接受
3. **解析器全纯函数 + HTML fixture 单测**：每校附 1 份脱敏后的课表页 HTML 快照（`resources/jw/<school>.html`），解析逻辑离线可测、CI 可测
4. **适配器贡献流程**：README 写「求你的学校适配」issue 模板，要求附课表页「另存为 HTML」（脱敏），社区 PR 加一个文件即可接入——框架价值大于初始覆盖
5. **依赖**：Jsoup（MIT，纯 Java，F-Droid 友好）
6. **不做**：自动持续同步教务（一次性导入）、任何形式的凭证存储、闭源适配器

## 任务划分（届时细化）

- T1 JwImportActivity + WebView 生命周期与 JS 桥
- T2 Adapter 框架 + 注册表 + 学校选择 UI（内置学校列表 + 「提交我的学校」入口）
- T3 首个学校适配（**从用户自己的学校开始**——实现前问用户哪个学校，拿真实课表页开发）
- T4 解析 → ImportPreview 接线 + fixture 测试
- T5 文档与贡献流程

## 风险

| 风险 | 说明 |
|---|---|
| 学校改版 | 适配器失效属正常损耗，warnings + 明确报错文案 |
| WebView 环境差异 | JS 兼容性保守写法（ES5）；evaluateJavascript 回调丢字符串长度超限 → 分段提取 |
| 政策/合规 | 仅做用户本人数据导入，无爬虫性质（用户登录、用户触发、本地解析）；GPL 生态惯例无碍 |
