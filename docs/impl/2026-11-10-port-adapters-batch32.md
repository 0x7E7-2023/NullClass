## 复审与修正

每件一个 reviewer 复审，主调度逐条核对代码后确认是真问题才动手，每条修正都配「独立手推期望的用例 / 冒烟场景 + 能捕获它的变异」：

- `nwpu`（2 条）：①学期下拉先取 `#semesters`，该元素存在但为空（页面脚本事后填充）时不回退 `#allSemesters`，
  整次导入报「读不到学期列表」；②AUDIT 里残留「4 个 GET / 降级通道」的写法。修正后新增冒烟场景 `empty-semesters`。
  另外**按安全红线删掉了上游 `getStdInfo` 学生信息接口**（只读课表），读不到 `dataId` 改为报错提示重开课表页。
- `suda`（3 条）：①隐藏判定只从 `<a>` 子节点开始，`<a>` 自身或祖先（隐藏 `<td>`）被隐藏时格子里的姓名 / 学号照样交出——
  隐私回归，改为沿祖先链 + `getClientRects()` 判定，新增冒烟 `hidden-cell`；②跳过行 / 稀疏节次等计数在去重之前累加，
  重复行会放大提醒，去重挪到最前，新增用例 `duplicate-rows`；③用例描述「缺教室 2 门」与实际 3 门不符。
- `swjtu`（1 条）：节次正则只在起始数字前允许「第」，`第1-第2节`、`第1至第2节`、全角数字整段认不出，
  课被当成「写法认不出」丢掉；先归一全角数字与起止符、终点侧也允许「第」，新增用例 `section-variants`。
- `xauat`（5 条）：①低周数提醒报「抬高后」的周数却说成校历周数（两条提醒自相矛盾）；②全部排课被跨学期规则丢掉时
  报错不写原因；③下课时间冲突按行数计却写「N 个开始时间」；④内容去重放在计数之后，重复行放大提醒条数；
  ⑤AUDIT 署名笔误。新增用例 `counters` 与冒烟场景 `all-before-start`。
- `lzu`（3 条）：①个人信息关键词含「民族」「性别」，课名「民族理论与民族政策」整行被当隐私删掉、课被错当教师名导入；
  关键词改为必须跟冒号，另保留长数字串拦法；②`linesOf` 只读 `innerHTML` / `textContent`，隐藏元素里的学号姓名照常交出，
  新增 `hiddenElement` + `visibleText` 并用到表头 / URP 格子 / 行兜底；③页面表头只给出部分节次时整张学校节次表被替换，
  低节次没有上下课时间且不提醒，改为逐节补齐并提醒。新增用例如 `partial-slots`、冒烟 `pii-course`。

## 未验证风险

- 五件都没有本校账号，未访问真实教务 / 统一认证，未做 Android 真机抽验；合成 fixture 与假站只证明转换逻辑。
- `lzu` 是 http 明文入口，且策略顺序按上游代码（网格 → URP → 课程列表 → 纯文本）；真实页面结构未验。
- `nwpu` 的 `getStdInfo` 降级通道没有移植：若某些部署的课表页里没有 `var dataId`，会报「没能在课表页面读到学生编号」，
  需要拿到真实页面再补读法。
- `suda` 仅校园网 / 校内 VPN 可访问，入口 http；`swjtu` 的 `ytoken` 若为 HttpOnly 且本地存储也没有，会停在「没有读到登录状态」。
- `xauat` 的节次时间按课表实际出现的开始时间推导（本校四个接口都不给作息表），若课程跨不同时段，节次表会偏多，提醒里如实说明。
