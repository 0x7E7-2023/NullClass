## 2. 脚本实际请求了哪些域与路径

### 上游脚本请求的

| 方法 | 地址 | 用途 |
|---|---|---|
| POST | `/jsxsd/jxzl/jxzl_query` | 教学周历（取开学日期） |
| POST | `/jsxsd/xskb/xskb_list.do` | 课表 HTML |

上游脚本里**没有任何绝对 URL**，两条都是相对路径（走当前页面的同源）。

### 本适配器请求的（`extract.js`）

| 方法 | 地址（**相对路径**） | 请求体 | 什么时候发 |
|---|---|---|---|
| POST | `/jsxsd/jxzl/jxzl_query` | `xnxq01id=<学期代码>` + `xqt=1&xqt=1&…&xqt=20&xqt=20`（与上游一字不差） | 每次提取都试一次；**失败不致命**（开学日期退回推算 + warnings） |
| POST | `/jsxsd/xskb/xskb_list.do` | `cj0701id=&zc=&demo=&xnxq01id=<学期代码>&sfFD=1&wkbkc=1`（与上游一字不差） | **只在**当前页面没有课表表格时才发（用户在课表页时直接用他看到的那张，不多发请求） |

两条都用 `credentials: 'same-origin'`、`Content-Type: application/x-www-form-urlencoded`；
响应非 2xx / 401 / 403 会带上「请先登录教务系统」的提示抛错。

**没有**绝对 URL、**没有**第三方域、**没有** CDN / 统计 / 加速器 / WebVPN 网关地址。
两个脚本里出现的 `https://github.com/…`（出处注释）与 `http://jwcmis.hnie.edu.cn`（出处注释里的
`import_url`）都在**注释**里，不是请求。

### `allowHosts`

```json
"allowHosts": ["jwcmis.hnie.edu.cn"]
```

- 写**精确主机名**（不是 `*.` 通配）：规范 §5（移植手册）里那条 —— `JwOriginRules` 会跳过通配项，
  写通配的适配器拿不到 OCR / 提问桥。**本件要用提问桥**（问作息），所以必须是精确主机名。
- 精确主机名同时让 `JwOriginRules.forAdapter` 为 `http://` 与 `https://` 各发一条 origin 规则，
  桥在两种协议下都能注入。
- `allowHosts` 只是**补充**：宿主本来就把 `loginUrl` 的主机放进白名单
  （`JwAdapter.allowedHosts` = `loginHost + manifest.allowHosts`）。这里显式再写一遍，
  一是让用户在安装前就看到「它会连哪台服务器」，二是万一 `loginUrl` 以后改指别处，
  请求目标也不会跟着漂。
- 两条路径都写成**相对路径**，所以即使用户是从别的入口（网关 / 别的主机名）进的教务，
  请求也落回**当前页面同源**的那台服务器，不会打到一个写死的内网地址上。

## 4. 读取面（`extract.js` 到底读了页面上的什么）

**逐条列全**（代码里所有 `document` / 节点读取点）：

1. **课表表格** `#timetable`（认不出就找「最近一张含 `.kbcontent` 格子的表」）：
   每行每个 `td` / `th` 的
   - `textContent`（格子的可见文字，`clean()` 后进载荷的 `text`）；
   - `colspan` / `rowspan` 属性（换算成网格列号 `col` 与 `span`）；
   - 该格内 `class` 含 `kbcontent` 的 `div` 的 **`innerHTML`**（课程明细原文，只取一份：优先
     `display:none` 的那份完整版）。**课程名 / 教师 / 教室 / 周次 / 节次全在 parse.js 里解释**，
     这里只搬原文。
2. **学年学期下拉框**：`<select>` 中 `id` 或 `name` 含 `xnxq` 的那一个，读它的
   `<option>` 的 `value` 与 `text`（只读选中项；没有选中项就取第一个形如 `2026-2027-1` 的）。
   这是**唯一**读页面文字的地方，且只读这一个控件。
3. **`window.location.href`**：只用于载荷里的 `pageUrl`（出问题时能看出用户是从哪个入口进的），
   不含任何个人信息。
4. **`new Date()`**：本地日期（载荷里的 `now`），只在教务给不出开学日期时用于推算第 1 周。
5. **教学周历**（`/jsxsd/jxzl/jxzl_query` 的**响应 HTML**，不是用户页面）：`#kbtable`
   （认不出就找第一张有 `td[title]` 形如「2026年09月07日」的表）里每个格子的 `textContent`
   与 `title` 属性。周历是**校历**，不含个人信息。
6. **`__ncCapabilities.ask` / `__ncSelect`**：问一次作息（冬令时 / 夏令时），见 §8 改动②。

**明确没读的**（可对照代码搜）：

- 成绩、学籍、个人信息、缴费、培养方案 —— 一个接口都没请求，页面上也没读这些区域；
- 账号密码 / 验证码 / 登录表单：不读、不填、不提交；
- `localStorage` / `sessionStorage` / `document.cookie`：**一次都没读**（脚本里没有这三个词）；
- 整页文字：没有 `document.body.textContent`、没有 `document.title`、没有 `innerText` 全页扫描
  （同平台的 `hynu` 曾经用过 `doc.body.textContent` 兜底找学期名，被收窄掉了；本件从一开始就没有）；
- 页面其它任何元素、任何属性。

**对页面只读**：脚本里没有 `document.createElement`、没有写 `innerHTML`、没有改表单、
没有 `.click()`、没有 `window.xxx = ` 的定义（上游那个写进页面的全局函数 `window.validateYearInput`
已删除）。上游的 `showAlert` / `showToast` / `notifyTaskCompletion` 也一并去掉 —— 空课自己的导入
流程会确认，适配器不需要（也不应该）往教务页面上画东西。

## 8. 移植改动（与上游逐条对照）

| # | 上游怎么做 | 这里怎么做 | 为什么 |
|---|---|---|---|
| ① | `showPrompt` 让用户手输起始学年 → `showSingleSelection` 选第一/第二学期 → 拼 `${year}-${year+1}-${n}` | 读课表页「学年学期」下拉框的**选中项** | 用户此刻就开在教务页面上，他切到哪一学期就导哪一学期，看得见自己选的是什么；少两个弹窗、少两处输错的机会。**没有用 __ncSelect 问学期** |
| ② | `showSingleSelection` 选作息（冬令时 / 夏令时） | **仍然问**，改成 `__ncSelect`（一次）；桥不可用或用户取消时按学期推（第二学期 = 夏令时，其余 = 冬令时；学期都不知道就按提取月份 4-9 月 = 夏令时）**并进 warnings** | 这两种作息下午 / 晚上的节次时间差 30-40 分钟（如第 5 节 14:00 vs 14:30），页面上没有这个信息，猜错了整学期的课表时间都偏。提问桥正是为「页面上没有、又必须用户定」的值准备的（规范 §5.2）。降级路径一定出声 |
| ③ | `parseWeeks()`：`weekStr.split('(')[0]` 后数数字 | `weeksIn()`：先去掉方括号（节次），括号逐个判性质（「周」字 / 教学班序号 / 单双标记），再按逗号与空白分段、**每段各自判单双** | 上游把单双标记连同 `(` 一起丢了（§7 第 1 条），且两段单双不同的写法（`1-8周(单),10-16周(双)`）会被前一段带走 |
| ④ | 节次 `weekStr.match(/\[(.*?)节\]/)` 后 `split('-')` 取首尾两个数 | `periodsIn()`：连字符、逗号（`[09,10节]`）、两位连堂（`[030405节]`）都认，取 min/max，**并在解析阶段夹住上限 MAX_PERIOD** | 上游只 `split('-')`，逗号写法会只剩一个数；不夹上限的话占位作息会补出 `24:00` 这种非法时刻，**整次导入会被载荷校验拒收** |
| ⑤ | `cells.forEach((cell, dayIndex) => day = dayIndex + 1)`：把「第几个 td」当星期几 | 每格带网格列号 `col` / `span`，按**表头给的列号**对齐；表头认不出按表宽兜底 | 课表首列是节次列（还常被 `rowspan` 跨两行），按下标算会整表错一天 |
| ⑥ | `mergeAndDistinctCourses()`：按名字排序 + 把相邻节次合并成一整块 | **不合并**：原样保留教务给的节次边界，只去掉完全相同的重复块（`blockKey` 去重） | 合并会把教务给的边界改写掉；相邻块在课表里本来就连着显示（应用按节次排），而「排序」不该由适配器做 |
| ⑦ | 课程块读 `div.kbcontent` 与 `div.kbcontent1` **两份** | 只取一份（优先 `display:none` 的完整版） | 同一个格子里两份是同一门课的简写与完整版，上游把两份都读，会把同一门课算两次（简写那份课名不同 → 变成两门课） |
| ⑧ | `teacher \|\| "未知教师"`、`position \|\| "未知地点"` | `null` | 规范 / 移植手册 §4.7：空着比写「未知」好（「未知」会当成真名显示） |
| ⑨ | 静默丢块（没课名 / 没节次就 `return`） | 分四类计数（没认出课名 / 周次 / 节次 / 节次超上限）+ **点名前 5 个**进 warnings | 「不许静默丢课」 |
| ⑩ | `showAlert` / `showToast` / `notifyTaskCompletion` / 往页面写 `window.validateYearInput` | 全删 | 空课的导入流程自己会确认；适配器不该往教务页面上画东西或写全局 |
| ⑪ | 开学日期：`parseWeekCalendar()` 从周历取「第 1 周周一」 | 同样从周历取，但**按表头认列**（单字 日一二三四五六），认不出就退回推算 + warnings；取到的日期若不是周一则按 §4.3 回退到那一周的周一**并出声** | 按位置猜列的话开学日期会错一整周，而它在库里和真值长得一模一样 |
| ⑫ | `semesterTotalWeeks: 20` 写死 | 20 为**下限**：周历给出的连续周数、课表里最晚的周次更大时往上抬（上限 30），抬了就出声；周历比 20 短时也出声说明按 20 计 | 学期长度直接影响「现在第几周」与最后几周的课会不会被 `totalWeeks` 卡掉 |

### `extract.js` 的网格逻辑（CI 跑不到，单独验）

`extract.js` 需要浏览器，CI 永远不执行它 —— 但它里面「算出 `col`」的那段（`partsOf` /

的根。2026-09-13 把这段函数**从 `extract.js` 源码里原样抠出来**（按函数名 + 花括号配对切片，
不是另抄一份），喂假的 `tr` / `td` 节点跑了 8 项断言，全部通过：

## 11. 已知不确定（交给真机抽验与用户反馈）

1. **fixture 是合成的**（测试方案 §3 允许，且要求注明）：按上游实际读取的字段形状编的，
   只保证「同样的输入永远给同样的输出」，**不保证**真实页面上解析得对。谁拿到真实页面 dump，
   替换 `fixtures/*.extracted.json` 是最高优先级的贡献。
2. **真实页面里 `#timetable` 到底有没有节次标签列**：有（首页 `col=0` 是「第1-2节」这类标签）
   与没有（7 列全是星期）两种形状本件都处理得了 —— 有表头时按表头列号，没表头时按表宽兜底。
   但如果真实表的表宽既不是 7 也不是 8 列、又没有表头，兜底会算错列（**会**进 warnings）。
3. **教学周历的表头是单字**（上游注释写的是「索引 0 周号、1 周日、2 周一…7 周六」）：
   本件按**单字表头**（日一二三四五六）认列，认不出就不取开学日期（退回推算 + warnings）。
   若真实周历的表头是别的写法，症状是「开学日期总是推算值」+ 预览里的那条警告。
4. **作息那一问**：`__ncSelect` 依赖提问桥。桥只在已知 origin 上注入（本件 `allowHosts` 是精确
   主机名，满足），但用户若从别的主机名进教务，桥不在 → 降级为按学期推断 + warnings。
5. **`allowHosts` 只写了 `jwcmis.hnie.edu.cn`**：如果学校还有别的入口主机（WebVPN / 另一台
   教务前置机），请求是相对路径（仍同源）所以能发出，但那条主机会被宿主当作白名单外的域拦掉 ——
   症状是提取失败并提示登录状态失效。真有这种入口时，把主机名补进 `allowHosts` 即可。
6. **分页盲区**：见 §7 第 6 条（接口不回总数，改成异步分页时我们无从察觉）。
7. **`loginUrl` 是 http**：应用会显示「不安全连接」标记。这是学校侧的现实（上游 `import_url`
   就是 http），没有替换成 https —— 换了可能连不上。
