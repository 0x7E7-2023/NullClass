### 非默认端口 `:5111` 对白名单的影响（这所学校特有的）

- **桥注入看 origin，origin 带端口**：`JwOriginRules` 按 `scheme://host[:port]` 生成规则，端口只可能
  从 `loginUrl` / `scheduleUrlHint` 里来 —— 所以 manifest 里这两个 URL **必须保留 `:5111`**，
  写成 `https://a.hblgxy.edu.cn/jsxsd/` 会让桥注入到 443 而不是 5111（页面里拿不到 `__ncCapabilities`）。
- **`allowHosts` 带不了端口**：`JwHostAllowlist` 的域名格式不接受 `host:port`，而且 `JwOriginRules`
  对 `allowHosts` 只补 `https://host` / `http://host`（默认端口）。所以 `allowHosts` 这一条对
  `:5111` 实际不起作用，它只表达「这台教务主机」；端口由 `loginUrl` 负责。
- **JS 沙箱按主机名匹配**（`JwScriptContract` 的 preamble 只看 `hostname`），所以脚本层拦不住
  「同主机换端口」—— 但我们的请求本来就是同源取数，没有额外的域要放行。
- **请求地址跟着页面走**：`extract.js` 的 `kbUrl()` 在「当前页就在 `a.hblgxy.edu.cn` 上」时用
  **当前页面的 origin** 拼 `/jsxsd/xskb/xskb_list.do`，只有在别的页面上跑时才回落到
  `https://a.hblgxy.edu.cn:5111`。学校换端口、走网关、或者用户从 http 登进来，脚本都不用改。

## 逐条（移植手册 §5）

1. **不碰凭据** — 不读 `password`/`pwd`/登录表单/`localStorage`/令牌，提取全程在用户已登录的页面里发生。
   上游用弹窗问的是**起始学年**（不是账号密码），移植后连这也不问了（学期从课表页的下拉框取）。
2. **不外发** — 两处请求都指向本校教务（`a.hblgxy.edu.cn:5111`）。没有 `sendBeacon`/`WebSocket`/
   `EventSource`/`new Image().src`，没有重定向后二次外发；`parse.js` 完全不联网（纯转换）。
3. **请求域可控** — 只有一个精确主机 + 唯一端口，见上。
4. **只读课表** — 只请求课表页。不碰成绩、学籍、考勤、缴费、个人信息。`extract.js` 读的页面内容只有
   课表表格与「与学期有关」的几处文字，逐条列在下面的**「读取面」**一节
   （这是本文件里**唯一**该被当作读取面依据的地方）。页面上的其它内容不读；读到的文字里即使夹着
   姓名/学号，也只有匹配到的那一小段会留下，进载荷的只有课表与学期名。
5. **不埋点** — 无统计、无上报、无遥测，也没有任何「回传失败原因」的请求。
6. **不 eval 远程代码** — 无 `eval` / `new Function`；取回的 HTML 只交给 `DOMParser`
   （惰性文档，不执行脚本）。
7. **不写页面** — 不写 DOM、不改表单、不触发提交、不点页面元素。上游往页面写过
   `window.validateYearInput`（给它自己的输入校验用的全局函数），移植后**连同弹窗一起删掉了**；
   `extract.js` 对页面只读（唯一写的是自己的局部变量与返回值）。
8. **不依赖用户输入之外的秘密** — 没有硬编码密钥、令牌、他人学号；`xnxq01id` 来自页面下拉框。

## 读取面（`extract.js` 到底读了页面上的什么）

本节 2026-09-12 与代码逐条对齐过（给的是函数名，不给行号 —— 行号会漂）。

| # | 读什么 | 代码位置 | 取出的值 | 去处 |
|---|---|---|---|---|

| 2 | 「学年学期」下拉框：id 或 name 含 `xnxq` 的 `<select>` | `readTerm()` 主路径 | 选中项的 value（`2026-2027-1`）与选项文字（学期名） | 载荷 `term` |

| 4 | 兜底②：页面上**每个** `<select>` 的 option 文字 | `termTextHints()` | 同上 | 见下 |
| 5 | 兜底③：id 或 class 含 `xnxq` 的元素的**短**文本（≤120 字） | `termTextHints()` | 同上 | 见下 |

兜底（3-5）只在下拉框认不出学期时才走，实现在 `termTextHints()` 一个函数里。它是**唯一**从
「非课表结构」取文字的地方，行为如下：

- 只在这三处取，**不读 `document.body`**（第 5 项还带长度上限，避免命中一个包着整页的容器）；
- 取到的整串文字只在本页内存里做一次正则匹配
  `(20\d{2})\s*-\s*(20\d{2})\s*学年\s*第?\s*([一二三123])\s*学期`；
- 匹配到了，**只把匹配到的那一小段**（如 `2026-2027学年第一学期`）当学期名，`term.code` 由正则的
  三个捕获组拼出来；没匹配到的文字不留引用、不记日志；
- 无论匹配与否都**不外发、不进载荷**、不写页面。`term.name` / `term.code` 是这条路径上唯一可能
  进载荷的东西，而且它们是学期名，不是页面上的其它内容。

另外 `extract.js` 会带一个 `now`（提取当天日期）出去，只用于教务给不出开学日时推算第 1 周 —— 日期
本身不是页面内容，是本机时钟。

## 与 hynu 的同平台对照片（0.980 相似度的两个脚本）

上游两个脚本做逐字 `diff`，只有三处不同：① 第 1 行的学校名；② `saveAppTimeSlots()` 里的作息表
（hynu 12 节 08:30 起 / hblgxy 14 节 08:00 起）；③ 请求的绝对地址（`hysfjw.hynu.edu.cn` /
`a.hblgxy.edu.cn:5111`）。也就是说**选择器、取数路径、周次与节次的写法，上游作者是当成同一套写的**：

| 层 | 是否可复用 | 本件的证据 |
|---|---|---|
| 接口信封（路径、请求体、返回结构） | 可复用 | 同一个 `POST /jsxsd/xskb/xskb_list.do`，body `cj0701id=&zc=&demo=&xnxq01id=`，返回服务端渲染的 HTML（不是 JSON） |
| 行字段名 / DOM 结构 | 可复用 | `#timetable` → `tr` → `td` → `div.kbcontent`，明细里 `font[title=教师|周次(节次)|教室]`，多门课用一长串 `-` 分隔 |
| 取数路径（要哪些参数、要不要先取学号） | 可复用 | 都不需要先取学号；学期要么用页面下拉框、要么 POST 指定 |
| 周次 / 节次编码 | 可复用（但**另外造了用例**） | 周次写在 `font[title=周次(节次)]` 的 `N-M(周)` 里、节次写在方括号 `[NN-NN节]` 里，两校写法一致 |
| 分页行为 | 不适用（两边都不是分页接口） | 见下面第 5 条 |

**这个「同平台」成立到什么程度**：成立在**脚本层**（两段上游代码除上述三处外逐字相同，所以选择器与
接口形状来自同一个作者、同一时刻的同一套假设）；**不成立的部分**是我们没有两校的账号，
`a.hblgxy.edu.cn:5111` 上的真实页面形状没有被真机验证过（见文末「已知不确定」）。因此本件没有照搬
hynu 的 `parse.js`：作息表、学期来源、列对齐、单双周与节次回落都单独过了一遍，并单独造了用例。

## 批次二对照清单（8 条，逐条结论）

1. **「单/双」写在「周」字后面** — **上游确实会丢**（`parseWeeks` 的 `weekStr.split('(')[0]` 把
   `(双)` 连同「周」之后的内容一起切掉，`1-16周(双)` 变成 1..16 每周都上，且不报警）。
   本件：`weeksIn()` 把「周」**整字删掉**（不是换成空格），单/双在段内直接认，被空白切成独立一段的
   标记再并回最近的周次段。用例：`basic` 的 `1-16周(双)`/`1-8周(单)`/`1-15(单)`，`edge` 的
   `1-16周(双)`。变异①（改回「周换空格 + 不并回标记」）→ 两对用例都变红（那一轮还没有 `serial`
   用例，所以只记 basic/edge 两格；本次 B8 复审只补跑了下面那两条新变异）。
2. **括号里的纯数字序号 `(1)` 不是周次** — 本平台的周次栏里只见到「(周)」这个量词括号，
   **没有从该校真实页面观测到序号括号**；这是按清单加的防御，不是实测形状（诚实说明）。
   实现：`SERIAL_PAREN` 把 `(纯数字)` 整组删掉，周次和节次两处都删（节次侧留着会把
   `01-02节(1)` 拼成 `01-021` 直接读废）。用例：`edge` 的 `9-16(周)(1)` 期望只有 9-16 周
   （不去掉防呆就会多出一段第 1 周）。变异② → `edge` 变红（`basic` 不含这个形状，故不红）。
   **批二复审补（B8）：序号组不只纯数字，还有数字区间** —— 实跑输入 `(1-2)1-16周[01-02节]`
   时，`SERIAL_PAREN` 只认纯数字，`(1-2)` 不被剥，于是第一个数字区间 `1-2` 成了周次，输出
   `startWeek 1 / endWeek 2`（应为 1-16），warnings 里也没有任何周次相关的提示。修法：新增
   `SERIAL_HEAD`，把**周次串开头**的括号组整组剥掉（纯数字或数字区间都算序号），并且必须放在
   「周」字删除**之前**做（否则 `(1-2周)` 也会长得像序号）；只剥「括号里除数字/区间什么都没有」
   的那一种 —— 带「周」「单」「双」的（`(1-2周)`、`1-16(周)`、`1-15(单)`）是正常周次形态。
   专用用例 `fixtures/serial.*`；变异⑮（去掉这一步）与⑯（判据放宽成串首任意括号）→ 该用例变红。
   同样是按缺陷单复现的输入，仍**不是**该校实测形状。
3. **读不出「第N节」不许静默丢课** — **上游在这里丢课**：`if (name && weekStr && start > 0)` 不成立
   就 `return`，一个字的提示都没有。本件三条路：① 认 `[NN-NN节]`/`[0708节]`/`[第9,10节]`；
   ② 格子里没给节次时回落到**所在行的「第N节」标签**（含 rowSpan 继承：这一行没有标签格子就沿用
   上一行的），并计数进 warnings；③ 两边都读不出，或周次读不出，才跳过并计数。
   用例：`basic` 的「军事理论 5-12(周)」（无方括号 → 行标签补上）、`basic` 的「创新创业教育 见通知」
   （缺周次 → 计数）、`edge` 表头后第一行（两边都读不出 → 计数）、`edge` 第 3 行（7 格短行 → 继承
   上一行标签）。变异③⑪ → 变红。
4. **连堂下 `periodTimes` 要覆盖每一节** — 内置表是上游那张 **14 节、1..14 连续**的表（原样搬），
   连堂 `[01-04节]`/`[05-08节]` 的每一节都在表内。课表用到表外的节次时（`edge` 的 `[15-16节]`）
   在 warnings 里点名「第 15、16 节没有上下课时间」，**不猜时间**。变异⑨（从表里删掉第 4、6 节）
   → 两对用例都红（同样只记 basic/edge 两格）。
5. **分页** — **不适用**：强智 `xskb_list.do` 一次返回整张 HTML 课表，接口没有分页参数也不回记录
   总数。会「只拿到一部分课」的只有 `zc`（周次过滤）这一个参数，本件与上游一样**留空**；
   拿不到表（没有一格的 `kbcontent` 有内容）时逐级报错，不会拿半张表入库。
6. **总周数被更晚的周次抬高要出声** — 教务不给总周数，上游写死 20 周。本件
   `totalWeeks = max(20, 课表里最晚的周次)`，**抬高时单独加一条 warning**（「课表里有第 22 周的课：
   学期总周数已按它给到 22 周…请核对是不是真实周次」）。用例：`edge` 的 `3-22(周)`。变异④
   （去掉抬高）→ `edge` 变红（注意：只改这一段而不改 warning，在真门的 `JwScheduleNormalizer`
   那一步也会因 `endWeek > totalWeeks` 被拦下）。
7. **AUDIT 声明与代码一致** — 本文件的「请求域」与「读取面」两节是唯一依据，均已 2026-09-12 与代码
   逐条核对；没有写比代码窄的声明（`extract.js` 读的三处兜底文字、`now` 都写在读取面里）。
8. **fixture 期望值独立推出 + 变异测试** — 三对 fixture 的 `expected.json` 是按规范手推的
   （不是把 `parse.js` 的输出贴进去），随后才跑比对，三个用例都 MATCH。变异测试共 16 条，
   逐条结果见 `AUDIT` 末尾一节；每条变异都至少让一个用例变红。

## 移植改动（`extract.js` / `parse.js`）

- **上游的弹窗与 toast 全部删掉**：`showAlert`（确认已登录）、`showPrompt`（输起始学年）、
  `showSingleSelection`（选第一/第二学期）、一串 `showToast`，以及给 `showPrompt` 用的
  `window.validateYearInput`。空课的导入流程自己会确认；学期改成从课表页的「学年学期」下拉框里取
  **选中的那一项**（用户在页面上切学期，适配器就跟着他走），并把学期名一起带出来。
- **上游的 `semesterTotalWeeks: 20` / `firstDayOfWeek: 1` / `savePresetTimeSlots`** 变成载荷字段
  （`totalWeeks` / `periodTimes`）+ warnings 说明：这些是适配器内置值，不是教务给的。
- **星期按表头列号对齐**：上游 `cells.forEach((cell, dayIndex) => day = dayIndex + 1)` 把「第几个
  格子」当星期几；强智这张表首列是节次列（上游自己的 `rows.slice(1)` 与 `cells.length < 7` 也在
  跳过表头），课程列的下标会比星期大 1。没有真实页面可赌，所以改成「有表头就按表头的列号取」，
  认不出表头才按「最后 7 列」兜底并报警；行比表头短（行首标签被 rowSpan 并掉）时按该行最后 7 列对齐。
- **教师/教室空着就留空**：上游写 `|| "未知教师"` / `|| "未知地点"`，本件给 `null` —— 「未知」会被
  当成真名显示（手册 §4.7）。
- **只取数**：`extract.js` 只交 `{now, term, rows[]}` 原始结构，周次/节次/课程名的解释全在
  `parse.js`（CI 里能真跑的那一段）。
